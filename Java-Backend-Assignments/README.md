# Java Backend Assignments — 3 Separate Projects

This archive contains three independent Spring Boot applications:
1. Student Record Management API
2. Contact Management System
3. To-Do List Backend

Each folder has its own `pom.xml`, Java source, MySQL configuration and README.
Use JDK 17+, Maven and MySQL 8+. Update each project's `application.properties`
with your local MySQL password before starting.

Start a project from its own folder using `mvn spring-boot:run`.
Each project uses port 8080 by default; stop one before starting another.
